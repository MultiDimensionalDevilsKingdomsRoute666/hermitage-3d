# ADR 0012 · Playwright e2e: CI smoke on software GL, pixel goldens local-only

## Context

architecture.md's budget table names the runtime rows "Draw calls ≤ 250 — HUD + Playwright
assertion" and "Triangles in frustum ≤ 1.0 M — same"; Phase 0 left the whole e2e route flagged
"unproven": golden frames were promised to run in CI on software GL, with the documented fallback
that flaky CI goldens move to local runs. Phase 1 had to prove or adopt the fallback. The
reference machine complicate the "prove it" path in two concrete ways discovered during round 11:
it runs macOS 13.7 (Chrome-for-Tested builds no longer publish a mac13 download slot — installed
with a `PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=mac14` bypass, Chrome's real floor being macOS 12), and
the headless compositor throttles rAF to ~5 fps (200 ms median) while the same build headed holds
60 fps — so *any* CI number is correctness-only and can never gate cadence.

## Decision

Round 11 adopts the fallback deliberately, not after flakiness:

- **CI (`e2e` job, separate from `checks`)** runs only the deterministic *smoke* project on
  GPU-less ubuntu with explicit SwiftShader launch flags (`--use-gl=angle --use-angle=swiftshader
  --enable-unsafe-swiftshader --ignore-gpu-blocklist`): det T1/T0 boots read the HUD `data-*`
  budget contract (tier label, draws ≤ 250, tris ≤ 1.0 M, `data-frame-ms` non-zero gate), clean
  console is asserted, settle bounds are generous hang detectors, never the ≤ 3 s device budget.
- **Pixel goldens run locally** on the reference Mac's real GPU in det mode (noon + the devlog-0000
  hero white night; page-level captures with a viewport clip because the locator path never passes
  Playwright's element-stability wait on a rAF-driven WebGL canvas; explicit 60 s assertion timeout
  because raw captures cost 2–6 s each). Baselines are platform-suffixed and committed
  (`tests/e2e/golden.spec.ts-snapshots/`); a flaky golden is the documented signal, never retried.

## Consequences

Budget assertions run on every push in CI (counts, tier labels, console); pixel truth is vouched
by the reference device only; baselines are not portable across platforms by design. Borrowed
CI hardware that renders on a real GPU can re-open CI goldens later. The headless throttle finding
is recorded here as the reason device-pass measurements run headed (devlog #0001 method note).
The parked runtime tier watchdog is unblocked by this round (golden frames now exist to catch
watchdog-driven boot composition changes).
