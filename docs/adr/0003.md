# ADR 0003 · No UI framework

- Status: accepted · 2026-10-15 · DEC-003

## Context

The DOM overlay is "nearly absent" by principle (roadmap): a wordmark, a time line, a hairline scrub control, later an index and a /notes page. This is six-ish elements with state that is already owned by a typed store and an explicit FSM.

## Decision

No UI framework: plain DOM elements driven by the coordinator. A typed store + explicit FSM is more legible at this size.

## Rejected alternative

A Preact overlay — a second component model for a nav and a time line, plus a build step and a runtime we do not need.

## Consequences

DOM updates are hand-gated (e.g. the title label churn guard in `src/main.ts`); if the overlay ever grows past a dozen live elements, this ADR is the place to reopen.
