# ADR 0006 · Assets as code

- Status: accepted · 2026-10-15 · DEC-006

## Context

Work is done by AI agents under owner direction (AGENTS.md); hand-edited binaries are unreviewable and unreproducible, and the reference machine is the constraint for bakes (roadmap).

## Decision

Every committed binary in `public/assets/` regenerates from a committed script in `tools/` (bpy / gltf-transform). One command regenerates a part deterministically; Blender runs locally headless, never in CI — CI validates the committed artifacts.

## Rejected alternative

Committing `.blend` files with hand edits — unreproducible, unverifiable.

## Consequences

Budgets can check artifacts in CI without running Blender; any asset change arrives as a script diff, reviewable like code.
