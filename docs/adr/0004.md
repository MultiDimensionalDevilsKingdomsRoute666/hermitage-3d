# ADR 0004 · Exterior: facade grammar + kit of parts

- Status: accepted · 2026-10-15 · DEC-004

## Context

Rastrelli's elevations are rule-governed: bay sequences, risalits, order heights, cornice profiles repeat across ~1900 windows. Hand-modelling months of unique geometry would kill both the schedule and the download budget, and bought/scanned assets carry licensing murk and style incoherence.

## Decision

The exterior is a typed facade grammar: bay sequences → a pure solver places ~25 instanced kit meshes. The generator itself is a portfolio artefact; ~1900 windows become a number, not a workload.

## Rejected alternatives

Hand-modelled facades (months before anything ships; download budget dies); scanned or purchased assets (licensing murk, style incoherence, payloads).

## Consequences

Phase 1 ships the grammar, solver and kit; correctness is golden frames against the documented spec, and the spec is published in-app (/notes v1).
