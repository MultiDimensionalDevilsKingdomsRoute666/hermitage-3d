# ADR 0002 · WebGL2 baseline; WebGPU as a later opt-in tier

- Status: accepted · 2026-10-15 · DEC-002

## Context

The project must reach every reviewer's browser on day one, and the drama is baked light plus a few effects — not compute. `three/webgpu` is a moving target; its API churn would couple the project to a renderer we do not control.

## Decision

WebGL2 baseline. WebGPU returns as a later opt-in tier, evaluated by ADR in Phase 4, by measurement.

## Rejected alternative

WebGPU-first with a WebGL fallback — months on the bleeding edge for no visual gain in Phase 0–3.

## Consequences

Shader work (the dome, DEC-0009) is written against WebGL2 conventions today; a WebGPU tier would revisit materials and post, never the pure sky modules.
