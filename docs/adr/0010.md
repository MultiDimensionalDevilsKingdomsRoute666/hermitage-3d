# ADR 0010 · No PMREM in Phase 0

- Status: accepted · 2026-10-15, relay round 2 · DEC-010

## Context

Phase 0's exterior is diffuse white massing. PMREM regeneration on clock movement is a non-preemptible GPU stall that returns at any cadence — the failure mode to remove, not rate-limit. The dome palette already encodes sky radiance for lighting purposes.

## Decision

`scene.environment` stays null; no PMREMGenerator, CubeCamera or environment render targets are imported or instantiated. Exterior lighting is a solar directional light (intensity 3·S(h/10)) plus a palette-derived hemisphere light (sky 0.25·Z + 0.75·H, ground 0.25·H); massing is Lambert. PMREM cadence is exactly zero; revisited by ADR in Phase 2 with interiors.

## Rejected alternative

PMREM regeneration on time changes — the bake jank is removed by removing the bake.

## Implementation

`src/main.ts` owns the two lights; nothing in the bundle references PMREMGenerator, and the §12 device gate records an invocation count of zero.
