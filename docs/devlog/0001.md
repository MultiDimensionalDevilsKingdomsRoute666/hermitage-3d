## Method note — headed vs headless

The same Chromium build and GPU produce a **200 ms median under CompositorIdleThrottling in headless while headed holds 16.6 ms** — headless runs on CI are correctness-only (counts, labels, console, pixels-locally); **no headless number is ever used as a cadence gate**, and the device pass runs headed. The HUD median measures compositor cadence, not app cost (devlog #0000 method note) — the §11 gate is claimed because a frame-hungry state would break the vsync-median; with the budget headroom shown, the median on both tiers pins to display cadence.
