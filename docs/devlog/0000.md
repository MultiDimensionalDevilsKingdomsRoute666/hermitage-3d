## Method note (Safari throttling removed by Apple)

Safari's Web Inspector no longer ships network throttling (the old experimental toggle was disabled in WebKit; bug 287737 tracks re-introduction). Instead of installing Xcode + Network Link Conditioner (system-wide, would also throttle the VPN), measurement ran in a **WKWebView harness** (`probes/measure.swift`, local-only): real WebKit on the reference Mac, production bytes, console piping, scripted scrub gesture, PNG snapshots.

Control experiment: a blank page with identical rAF accounting in the same harness also shows a 33.3 ms cadence (WebKit's adaptive rAF throttling flips 30↔60 fps between runs — live-time runs capped at 30, fixed-time runs ran at 60). Per-frame deltas therefore measure compositor cadence, not app cost; the app's own per-frame work is bounded by the 13 draws / 135 tris above. The 10 Mbps condition adds ~0.11 s of transit to the 136 KB bundle; first-sky well under the 3 s gate with margin.
